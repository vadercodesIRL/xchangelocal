XchangeLocal is a Consumer-to-Consumer (C2C) marketplace built for South Africa, allowing everyday users to buy and sell goods directly with each other online.

Built from scratch with PHP, MySQL, HTML, CSS, and JavaScript — no frameworks, no CMS. Features include secure user authentication, role-based access control across five user roles, a full order lifecycle with a 2% commission model, verified seller badges, star ratings, dark mode, and a fully responsive mobile-first design.

Stack: PHP 8 · MySQL · Vanilla JS · CSS Design Tokens · InfinityFree Hosting
